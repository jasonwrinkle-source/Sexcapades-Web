# The AntiGravity Edition

AntiGravity's songbook, versioned separately from YoBiche's standing
book (`songbook/`). It versions its own lyrics here — it never
overwrites the main book.

## Versions

- **v1.0** (`v1.0/ANTIGRAVITY-SONGBOOK.md`) — its first book: four
  tracks (I–IV) + style prompts A1–A4 + a glossary coverage matrix.
  Committed by Jason 2026-11-25 (fdacb51). Scored 54.5–66 against
  YoBiche's v5.1.1 on the eight-factor card (corrected from 52 — the
  distinct byline and the number bounds were Jason's orders, not
  violations).
- **v5.1.3** (`v5.1.3/`) — its third attempt: a full revision of
  YoBiche's v5.1.2 book, 8 universal songs + 22 per-skin songs +
  docs, committed by Jason 2026-11-25 (47b1269). Scored against
  v5.1.2 on the same card. Its manifest is
  `v5.1.3/ANTIGRAVITY-SONGBOOK.md`.

## The rule

A new AntiGravity attempt gets a new versioned directory here
(`v5.1.4/`, …). It does not edit `songbook/` — the main book is
YoBiche's, and lines from an AntiGravity edition enter it only when
Jason rules them in, one at a time.

(The `SONGBOOK-v5.1*.md` prompt files inside `v5.1.3/` are YoBiche's,
carried over in the snapshot — they document the prompt lineage, not
AntiGravity's lyrics.)
