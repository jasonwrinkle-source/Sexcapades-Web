## Shape

Two tiers, matching the thing itself (one engine, many hypermaps):

- **`universal-set/`** — songs true of the engine and the application
  as a whole, sung the same way on every skin:
  - `U1-What-Its-For.md` (The Flagship)
  - `U2-One-Engine-Many-Maps.md`
  - `U3-Rate-What-You-Hold.md`
  - `U4-Three-Operations.md`
  - `U5-Bring-Your-Map.md`
  - `U6-The-Meeting-After-The-Meeting.md` (carried over from the explainer album)
  - `U7-Many-Views-Under-One-Roof.md` (the views in action)
  - `U8-Cards-Sheets-Packs-Veils.md` (how hypermaps travel)
- **`per-skin/`** — one signature song per skin for all 22 skins:
  Aesthcapades, Biocapades, Chemcapades, Dancecapades, Dharmacapades,
  Expericapades, Fastcapades, Flexcapades, Forescapades, Linguacapades,
  Mattercapades, Nouscapades, Philoscapades, Poliscapades, Praxicapades,
  Quantacapades, Questcapades, Sexcapades, Simulcapades, Techcapades,
  Theoricapades, Vocapades.

Playback fallback in the app: a skin's own song first, then the
Universal Set, then the TaxoPolemics album.

## Standing rules

Lyrics are independent of style (each set carries a `STYLE.md` with
the Suno treatment strings; track files hold lyrics only and name
their treatment). All songs SFW by construction. Verified glossary and
word-count audit lives in [`COVERAGE.md`](COVERAGE.md).
