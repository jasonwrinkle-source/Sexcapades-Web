                      FetLife Import — How It Works

                      1. Save your FetLife profile page with your browser’s “Save Page As” (HTML).
                      2. Upload the saved file — or paste the HTML — into the FetLife importer.
                      3. The importer extracts the Fetishes section: the “Into” and “Curious about” lists.
                      4. Each fetish is looked up in the importer’s mapping table.
                      5. “Into” fetishes are mapped to topics with “interested” ratings (green).
                      6. “Curious about” fetishes are mapped with “curious / neutral” ratings (yellow).
                      7. Fetishes with no mapping go to an “unmapped” list shown with a warning — they are not silently dropped.
                      8. Anonymous importer feedback (opt-out): with your permission, the importer sends just those unmatched fetish names — and whether each appeared in your “Into” or “Curious about” list — so the mapping tables can be improved and more fetishes map correctly in the future. The only identifier sent is the app's anonymous analytics UUID — a random ID that isn't linked to your name, account, or profile. No profile data, no ratings, and no personally identifying information is sent — only the unmatched names and that anonymous UUID. This follows the same opt-out pattern as the anonymous ratings contribution: the “Help improve imports by sharing unmatched fetish names anonymously” box in the FetLife import dialog is checked by default, and if you uncheck it, nothing is sent.
                      9. If a “View all” link remains inside the Fetishes section (under Into, Curious About, or another fetish list), a truncation warning appears: the saved list may be incomplete. “View all” links elsewhere on the page are ignored.
                      10. Limitations — please read: the mapping tables were built quickly and are low-confidence. Some fetishes will not map to existing topics, some mappings may be wrong, and the table may not reflect the latest FetLife categories. Always review the imported results before trusting them.
